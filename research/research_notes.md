# 通用 EQA 记忆框架 - 研究笔记

> 本文档为研究结论存档，用于跨对话延续。每次新对话开始时，CLAUDE 应先读本文件了解上下文。
> 配套文件：`papers_matrix.md`（论文×记忆模块矩阵）、`references.bib`（文献库）

---

## 1. 研究目标

设计一个**通用 EQA（具身问答）智能体记忆框架**。

核心设计哲学（用户原话）：
> 不同 EQA 方法的记忆模块"难以向下兼容，但可以通过抽象的方法进行向上兼容"——
> 即，通用记忆框架为众多不同类型的记忆**预设位置（槽位）**，不同 EQA 方法按需存储记忆。

**关键定位**：框架定义**接口契约**而非具体实现。不同方法 plug-in 自己的实现即向上兼容。

## 2. 调研方法论

- 两轮并行文献调研，累计 ~65 篇论文
- 第一轮：按 5 大记忆类别（空间/图/情景/认知/LLM-VLM）覆盖经典与基础工作
- 第二轮：聚焦 2025-2026 多记忆融合论文 + 用户点名的 4 篇（R4, Pred-EQA, INHerit-SG, WorldMM）
- 范围：EQA 为主，紧邻方向（VLN、具身Agent、移动操作、终身机器人）作为可迁移来源

## 3. 核心发现

### 3.1 收敛的 6 个记忆槽位

所有论文的记忆模块可归入 6 个功能槽位（见 `papers_matrix.md` 第一节）：
1. **WM** 工作记忆 — 当前观测、任务状态、近期上下文
2. **SG** 对象-关系/场景图记忆 — 层级对象拓扑
3. **GM** 空间-几何记忆 — 度量地图、占用、导航可行
4. **EM** 情景记忆 — 时序事件、观察序列
5. **SM** 语义/知识记忆 — 事实、规则、常识
6. **PM** 程序/技能记忆 — 动作策略、能力profile

### 3.2 没有论文占满全部 6 槽位
最接近的是 HIMM(5) 和 CRAM 2.0(5)。→ 通用框架的"通用性"价值真实存在；占满 6 槽位能否提升是可验证研究问题。

### 3.3 记忆的 3 个正交维度
所有记忆系统都在沿这三轴组合：
- **时间尺度**：感觉缓存 / 工作 / 长期 / 跨episode
- **内容类型**：几何空间 / 对象关系 / 事件 / 语义 / 动作
- **表征格式**：原始感知 / 特征向量 / 结构化符号 / 参数化权重

### 3.4 7 种记忆融合模式（2025-2026 主流）
1. 空间-语义双记忆（最主流）
2. 情景-语义认知对（最主流，带consolidation）
3. 短期/长期时序
4. 控制/数据面分离（Pred-EQA 首创明确表述）
5. 神经-符号
6. 视觉-文本互补
7. 参数化-非参数化

## 4. 通用记忆框架设计 v2

```
通用EQA记忆框架 (v2)
├── [即时层]
│   └── 工作记忆 (当前观测 + 任务状态 + 近期上下文)
│
├── [情景层] (单episode内)
│   ├── 空间-几何记忆 (GM)
│   ├── 对象-关系记忆 (SG)  ← 含层级 + 视角指针
│   └── 情景记忆 (EM)       ← 含多时间尺度
│
├── [长期层] (跨episode)
│   ├── 语义/知识记忆 (SM)  ← 含 episodic→semantic consolidation
│   ├── 程序/技能记忆 (PM)
│   └── 变化检测记忆 (可选) ← 支撑动态环境QA
│
└── [横切机制]
    ├── 写入: 连续 / 事件触发 / 学习式 / 门控
    ├── 读取: 固定检索 / 迭代Agent / 并行+critic仲裁
    ├── 沉淀: episodic→semantic consolidation
    ├── 遗忘: 容量 / 局部子图更新 / VoI停止
    └── 多模块分发: planner + stopper + answerer
```

### 框架对 6 槽位的接口要求（每个槽位需定义）
- `write(observation, context)` / `update()`
- `read(query)` / `query(filter)`
- `consolidate(other_memory)`（跨模块沉淀）
- 实现者按需 plug-in 具体数据结构

## 5. 最值得借鉴的 7 个新概念（写论文时的卖点）

1. **对象级多轴索引**（R4）— 同一对象在语义/空间/时间三轴各建索引，任一查询返回完整记录
2. **控制面/数据面分离**（Pred-EQA）— 文本决策记忆(慢)与视觉证据记忆(快)解耦
3. **事件触发写入**（INHerit-SG）— 不每帧写，只在拓扑事件触发
4. **自适应检索Agent**（WorldMM）— 轻量agent决定"接下来查哪个记忆"
5. **学习式写/遗忘策略**（EPM, ICLR 2026）
6. **语言为中心锚定**（INHerit-SG/R4/WorldMM）— 文本为主接口，embedding辅助
7. **并行查询 + critic仲裁**（RoboMemory）

## 7. 开放问题 / 待研究方向

1. **槽位粒度**：6 个是否过多？是否合并为"陈述性记忆"(EM+SM) + "结构化空间记忆"(SG+GM)？粒度取决于强调差异化还是共性。
2. **跨episode**是否作为独立维度层？目前只有 Ella/LEGION/ReMEmbR/HIMM 支持。
3. **接口标准化**：每个槽位的 write/read/query 签名需进一步调研每个方法的 I/O 才能定义。
4. **技能记忆**在纯 EQA（非manipulation）中如何体现？可能映射为"探索策略记忆"。
5. **变化检测**应作为独立槽位还是 GM 的子能力？
6. **可学习记忆管理**能否统一现有门控/触发/遗忘机制？

## 9. 用户点名的 4 篇论文速查（多记忆融合典型）

### R4 (arXiv 2512.15940)
- **记忆**：每对象 = 语义描述(SEM) + 空间位置(SPA) + 时间区间(TEM) + SLAM度量地图
- **融合**：三轴是同一对象记录的三条索引，任一key检索都返回完整4D记录
- **结果**：ERQA 70.25% 超 GPT-5 (65.7%)；仅用 4B VLM

### Pred-EQA (CVPR 2026)
- **记忆**：文本结构记忆(慢，存决策/规划) + 视觉快照记忆(快，问题相关图像)
- **融合**："控制面 vs 数据面"分离；预测-执行-过滤-修正闭环；纯VLM无场景图
- **代码**：github.com/yuanrr/Pred-EQA

### INHerit-SG (arXiv 2602.12971)
- **记忆**：4层层级图 楼层→房间→功能区→物体；物体节点带指针指向独立图像hash表
- **融合**：双流异步(快几何2Hz + 慢语义15s/帧) + 事件触发 + 闭环检索(VLM验证)
- **结果**：存储 47.5MB vs ConceptGraphs 18.47GB；HM3DSem-SQR 36.3% SOTA

### WorldMM (arXiv 2512.02425)
- **记忆**：情景记忆(多时间尺度KG: 30s/3min/10min/1h) + 语义记忆(演化KG带consolidation) + 视觉记忆
- **融合**：自适应检索Agent迭代决定查哪个记忆；情景→语义自动沉淀 Consolidate(G,T)
- **结果**：5基准均分 69.5% (+8.4%)
